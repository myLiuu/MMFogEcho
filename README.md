# MMFogEcho
Official repository for the MMFogEcho real-fog multimodal dataset.

**MMFogEcho** is a real-fog multimodal dataset associated with our work on LiDAR echo-based measurement under foggy conditions.

## Overview

The dataset was collected under controlled real-fog conditions for the study of multimodal LiDAR echo processing and measurement in scattering environments. The experimental platform incorporates synchronized LiDAR and imaging sensors to capture complementary information under different conditions.

## Dataset Availability

A public release of the MMFogEcho dataset will be made available through this repository upon publication of the associated paper.
